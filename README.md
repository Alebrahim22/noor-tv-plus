# 📺 نور تي في بلس

### نظّف تلفزيونك من الإعلانات، وخلّه يأذّن على المذهب الجعفري

نسخة مبنية على [نور تي في](https://github.com/majedphotos/noor-tv) لماجد. كلود يسوي كل شي، ويمشّيك خطوة خطوة بكلام بسيط.

## شنو بتحصل؟

| | |
|---|---|
| 🕌 **الأذان 3 مرات** | الفجر، والظهرين، والعشاءين، بصوت محمد بوجبارة. بدون إقامة. لو فيلم شغال يطلع شريط بس وما يقطع عليك |
| 🧭 **مواقيت جعفرية بدون نت** | الفجر 16°، المغرب بعد ذهاب الحمرة (4°)، العشاء 14°. محسوبة على التلفزيون نفسه، وتعدّل دقايق كل صلاة من جوالك |
| 📿 **الأدعية بوقتها** | دعاء الندبة كل جمعة 10:30 الصبح، ودعاء كميل كل خميس 8:30 بالليل، تشتغل بروحها |
| 🌙 **المناسبات الجعفرية** | فوق الساعة: المواليد بالذهبي، والوفيات بسطر هادي، على التاريخ الهجري اللي تعدّله حسب إعلان المرجع |
| 💌 **صفحة الجوال** | برمز من 4 أرقام: تكتب وترسم على الشاشة، وتغيّر المواقيت والهجري ووقت الأدعية |
| 🧹 **بلا إعلانات** | يعطّل تطبيقات الشركة اللي تعرض إعلانات وتتبّعك (تعطيل مو حذف، وترجع بأمر واحد) |
| 📖 **كروت بضغطة** | الكهف، البقرة، أذكار الصباح والمساء، الرقية، الندبة، كميل |

## يشتغل على شنو؟

✅ أندرويد تي في وقوقل تي في (أندرويد 8 أو أحدث): تي سي إل، سوني، شاومي، هايسنس أندرويد، فيليبس أندرويد...
❌ سامسونق وإل جي (أنظمتهم مو أندرويد)

## تحتاج

1. لابتوب ويندوز أو ماك فيه [كلود كود](https://claude.com/claude-code)
2. التلفزيون واللابتوب على **نفس الواي فاي**

## الطريقة

**1.** افتح كلود كود بمجلد هالريبو، وقول له:

```
نظّف تلفزيوني واقرا skills/noor-tv-plus/SKILL.md وامشِ عليه خطوة خطوة
```

**2.** سوّ اللي يقول لك. الشي الوحيد اللي تسويه بإيدك: تضغط 7 مرات بإعدادات التلفزيون عشان تفعّل «خيارات المطوّر».

**3.** خلاص. يعطيك تقرير بكل شي، ورابط صفحة الجوال والرمز.

## ⚠️ اقرا قبل ما تبدي

- **عطّل لا تحذف.** هالسكل ما يحذف تطبيقات التلفزيون أبداً، يعطّل بس، والسكربت يرفض حزم النظام الأساسية.
- قبل أي تغيير تنحفظ نسخة احتياطية بجهازك، ومعها أمر يرجّع كل شي.
- كلود يستأذنك قبل كل دفعة.
- الاستخدام على مسؤوليتك.

## Everything needed is in this repo
- `noor-app/` – Android source, including the Kahf audio in `app/src/kahf/res/raw/`
- `dist/` – built release APKs for all 7 variants (ready to install on the TV with adb)
- `source-audio/` – original uncompressed adhan recording
- `docs/noor-tv-comparison.html` – the skills comparison page
